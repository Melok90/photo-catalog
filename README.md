# Photo Catalog — Мобильный фото-сканер (PWA)

Минималистичное мобильное прогрессивное веб-приложение (PWA), ориентированное в первую очередь на **iPhone**, предназначенное для сверхбыстрой фотосъёмки объектов и надёжного сохранения в локальную электронную картотеку на базе **IndexedDB**.

---

## 📸 Основные возможности

1. **Камера и съёмка:**
   - Автоматический выбор и запуск основной задней камеры смартфона в высоком разрешении.
   - Возможность переключения между задней и фронтальной камерами.
   - Большая кнопка спуска затвора с тактильной анимацией и виброоткликом (Haptic feedback).
   - Полноэкранный видоискатель с адаптацией под безопасные зоны iPhone (Safe Area Insets / Dynamic Island / Notch).

2. **Два режима съёмки:**
   - **Одиночный режим:** после съёмки открывается превью снимка с действиями «Сохранить» или «Переснять».
   - **Режим непрерывной съёмки (Серия):** съёмка в одно касание, мгновенное фоновое сохранение снимка в картотеку и готовность к следующему объекту без остановки видеопотока.

3. **Локальная электронная картотека:**
   - Хранение всех фотографий в базе данных браузера **IndexedDB**.
   - Автоматическая генерация оптимизированных миниатюр (thumbnails) для моментальной плавной прокрутки сетки без перегрузки оперативной памяти.
   - Хранение оригинала в полном разрешении.
   - Сортировка по времени съёмки (новые сверху).
   - Полноэкранный просмотр (Lightbox) с детальной информацией: дата и точное время создания, разрешение в пикселях, вес файла.
   - Скачивание любого снимка на устройство и удаление с подтверждением.
   - Индикатор свободной памяти устройства (`StorageManager API`).

4. **Резервное копирование и восстановление:**
   - **Экспорт в ZIP-архив:** скачивание стандартного архива со всеми оригинальными `.jpg` фотографиями и индексным файлом метаданных `catalog.json` (работает полностью офлайн на чистом JS без сторонних библиотек).
   - **Полный JSON бэкап:** переносимый снимок картотеки для моментального восстановления.
   - **Импорт / Восстановление:** загрузка ZIP-архива или JSON-файла с автоматическим добавлением снимков в базу.

5. **Автономность и PWA:**
   - Полная работоспособность без подключения к интернету (100% Offline) благодаря Service Worker.
   - Установка на экран «Домой» (Add to Home Screen) на iPhone как нативное iOS-приложение.
   - Нулевой трафик на сторонние серверы — приватность гарантирована, все данные остаются на устройстве.

## 🛠 Технологический стек

- **HTML5** (Семантическая разметка, Audio/Video MediaStream).
- **CSS3** (Apple Human Interface Guidelines, CSS Custom Properties, Safe Area Insets, Flexbox/Grid).
- **Vanilla JavaScript (ES Modules)** — без React/Vue/jQuery или тяжелых внешних зависимостей.
- **MediaDevices API** (`getUserMedia`, `enumerateDevices`).
- **IndexedDB** (`IDBDatabase`, индексы курсоров по времени).
- **Service Worker & Web App Manifest** (кэширование Cache API, PWA Standalone).

## 🚀 Локальный запуск и тестирование

> **Важно:** Доступ к камере смартфона в браузерах защищён требованиями безопасности: камера работает только через **HTTPS** или **localhost**.

### Вариант 1. Запуск через Python (встроенный сервер)

В терминале перейдите в папку проекта и выполните:

```bash
cd /Users/melok/.gemini/antigravity/scratch/photo-catalog
python3 -m http.server 8080
```

Откройте в браузере: `http://localhost:8080`

### Вариант 2. Запуск с доступом по локальной сети с iPhone

Чтобы протестировать приложение прямо с iPhone в домашней Wi-Fi сети:

1. Узнайте локальный IP-адрес вашего компьютера (например, `192.168.1.50`).
2. Для запуска HTTPS-сервера можно использовать утилиту `mkcert` или `caddy`, либо воспользоваться туннелем:
   ```bash
   npx localtunnel --port 8080
   # или
   ngrok http 8080
   ```
3. Откройте полученную `https://...` ссылку в Safari на iPhone.

## 📱 Установка на iPhone (PWA)

1. Откройте страницу приложения в **Safari** на iPhone.
2. Нажмите кнопку **«Поделиться»** (иконка квадрата со стрелкой вверх внизу экрана Safari).
3. Прокрутите меню вниз и выберите **«На экран "Домой"»** (Add to Home Screen).
4. Нажмите **«Добавить»** в правом верхнем углу.
5. На рабочем столе появится иконка **Photo Catalog**, которая открывается на весь экран без адресной строки браузера и работает даже при отсутствии сети.

## 🌐 Публикация на GitHub Pages

Проект уже содержит файл GitHub Actions (`.github/workflows/deploy.yml`), который автоматически публикует сайт при пуше в ветку `main`.

### Шаги для публикации в ваш репозиторий:

1. Создайте новый репозиторий на [GitHub](https://github.com/new) (например, `photo-catalog`).
2. В терминале в папке проекта выполните команды:

```bash
cd /Users/melok/.gemini/antigravity/scratch/photo-catalog

# Инициализируйте git (если ещё не инициализирован)
git init -b main
git add .
git commit -m "feat: initial release of Photo Catalog PWA"

# Привяжите ваш удалённый репозиторий (замените USERNAME на ваш логин GitHub)
git remote add origin https://github.com/USERNAME/photo-catalog.git

# Отправьте код на GitHub
git push -u origin main
```

3. В настройках репозитория на GitHub:
   - Перейдите в **Settings** -> **Pages**.
   - В разделе **Build and deployment** -> **Source** выберите **GitHub Actions**.
   - Workflow запустится автоматически, и через 1 минуту ваше приложение будет доступно по защищённому адресу HTTPS:
     `https://USERNAME.github.io/photo-catalog/`

## 🔒 Безопасность и хранение данных

- Все фотографии сохраняются исключительно в изолированной локальной базе данных устройства (**IndexedDB**).
- Никакие изображения или персональные данные не отправляются на удалённые сервера.
- Приложение предупреждает пользователя при приближении к лимиту памяти устройства.
